### ⚡ About

Low-level software developer interested in systems architecture, virtual machines, and native Linux utilities. I focus on writing high-performance, memory-safe software with clean architectures and zero bloat.

- 🛠 **Languages:** C, C++20, Rust, Python, Java
- 🐧 **Platform:** Linux (NixOS / Wayland)
- 🎯 **Focus:** System-level applications, emulators, server infrastructure
